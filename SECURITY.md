# Security Policy

## Supported Versions

This is an experimental/toy project developed in a 6-hour hackathon. Only the latest version pushed to this repository is active.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < Last  | :x:                |

## Reporting a Vulnerability

Since this is a personal, experimental project, there is no official security team. If you find any critical security vulnerabilities, please do not open a public issue. Instead, just let me know or open a Pull Request with the fix. Thank you!
